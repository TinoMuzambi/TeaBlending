\section{1 Introduction}\label{introduction}

This document presents a comprehensive analysis of the tea blending
optimisation problem using multiple computational approaches. The
problem requires determining the least-cost combination of raw materials
to produce final blends that meet specific quality characteristics, as
formalised by Fomeni (2018).

The primary objectives are:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  To implement and solve a cost-minimisation model using Linear
  Programming (LP).
\item
  To solve the same problem using Simulated Annealing (SA) metaheuristic
  and compare performance.
\item
  To formulate and solve a multi-objective model using Chebyshev Goal
  Programming.
\item
  To explore Genetic Algorithms (GAs) as an alternative solution
  approach.
\end{enumerate}

\section{2 Problem Formulation and Data
Preparation}\label{problem-formulation-and-data-preparation}

\subsection{2.1 Notations and
Parameters}\label{notations-and-parameters}

\begin{itemize}
\tightlist
\item
  \textbf{Indices}:

  \begin{itemize}
  \tightlist
  \item
    \(i\): Index for raw materials
  \item
    \(j\): Index for final blends
  \item
    \(k\): Index for quality characteristics
  \end{itemize}
\item
  \textbf{Parameters}:

  \begin{itemize}
  \tightlist
  \item
    \(P_i\): Unit cost of raw material \(i\) (£/Kg)
  \item
    \(D_j\): Weekly demand for final blend \(j\) (Kgs)
  \item
    \(a_i\): Weekly availability of raw material \(i\) (Kgs)
  \item
    \(g_{ik}\): Grade of characteristic \(k\) in one unit of raw
    material \(i\)
  \item
    \(s_{jk}\): Required target score of characteristic \(k\) in one
    unit of final blend \(j\)
  \end{itemize}
\item
  \textbf{Decision Variables}:

  \begin{itemize}
  \tightlist
  \item
    \(x_{ij}\): Amount (in Kgs) of raw material \(i\) to be used in
    final blend \(j\)
  \end{itemize}
\end{itemize}

\section{3 Approach 1: Cost Minimisation using Linear
Programming}\label{approach-1-cost-minimisation-using-linear-programming}

This section implements the cost-minimisation model using Linear
Programming with parametric relaxation of the characteristic-matching
constraints.

\textbf{Assignment Expectations}: The technical report requires
implementing a cost-minimisation LP model that finds the optimal
combination of raw materials to produce blends meeting demand and
quality constraints. This implementation uses Rglpk (direct GLPK
interface) as specified in the assignment requirements, which provides a
straightforward matrix-based formulation that is well-suited for this
problem type.

\subsection{3.1 Model Formulation}\label{model-formulation}

\textbf{Objective Function}: Minimise total cost
\[\min \sum_{i} \sum_{j} P_i x_{ij}\]

\textbf{Subject to Constraints}:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Raw Material Availability: \(\sum_{j} x_{ij} \le a_i \quad \forall i\)
\item
  Blend Demand: \(\sum_{i} x_{ij} \ge D_j \quad \forall j\)
\item
  Characteristic Score Relaxation:

  \begin{itemize}
  \tightlist
  \item
    \(\sum_{i} (g_{ik} - (s_{jk} + \epsilon_{jk})) x_{ij} \le 0 \quad \forall j, k\)
  \item
    \(\sum_{i} (g_{ik} - (s_{jk} - \epsilon_{jk})) x_{ij} \ge 0 \quad \forall j, k\)
  \end{itemize}
\item
  Non-negativity: \(x_{ij} \ge 0 \quad \forall i, j\)
\end{enumerate}

\section{4 Approach 2: Cost Minimisation using Simulated
Annealing}\label{approach-2-cost-minimisation-using-simulated-annealing}

as the algorithm ``cools down.''

\section{5 Approach 3: Multi-objective Optimisation using Chebyshev Goal
Programming}\label{approach-3-multi-objective-optimisation-using-chebyshev-goal-programming}

Chebyshev Goal Programming minimises the worst-case deviation from
multiple goals, providing a balanced solution that trades off cost for
quality control.

\subsection{5.1 Model Formulation}\label{model-formulation-1}

\textbf{Objective Function}: Minimise worst-case deviation
\[\min \max\{w_0 \cdot d_0, w_{jk} \cdot d_{jk}\}\]

Where: - \(d_0\): Deviation from cost goal - \(d_{jk}\): Deviation from
quality goal for blend \(j\), characteristic \(k\)

\textbf{Constraints}: - All LP constraints - Goal constraints for cost
and quality

\subsection{5.2 Implementation}\label{implementation-2}

\section{8 Conclusion}\label{conclusion}

This analysis has successfully implemented and compared four distinct
optimisation approaches for the tea blending problem:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Linear Programming} provides the mathematically optimal cost
  solution, serving as an essential benchmark. However, it treats
  quality deviations as hard constraints within tolerance, not as
  objectives to minimise.
\item
  \textbf{Simulated Annealing} offers a flexible metaheuristic approach
  that can find near-optimal solutions efficiently, valuable in dynamic
  operational environments where exact optimality is less critical than
  solution speed.
\item
  \textbf{Chebyshev Goal Programming} provides a superior framework for
  balancing cost and quality objectives. By formally incorporating
  decision-maker preferences through goals and weights, it delivers
  balanced, actionable solutions that directly manage the trade-off
  between production cost and product quality.
\item
  \textbf{Genetic Algorithms} demonstrate another powerful evolutionary
  approach, capable of exploring complex solution spaces and finding
  good solutions through population-based search.
\end{enumerate}

The comparative analysis reveals that while LP provides the lowest cost,
multi-objective approaches like Chebyshev Goal Programming are better
aligned with business realities where maintaining brand integrity
through consistent quality characteristics is as important as minimising
cost.
